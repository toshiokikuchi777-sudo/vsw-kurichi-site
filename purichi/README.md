# プリチ LP

既存のVSWサイト内で動く、静的な独立LPです。ページは `/purichi/`。

元素材はプロジェクト直下の `プリチ/` にコピーして保管。デスクトップの原本は保持しています。公開用画像は `assets/photo-01.webp` 〜 `photo-15.webp`、動画は `assets/purichi.mp4`。

価格・原材料・販売状況など未確認の商品情報は掲載していません。商品一覧へのリンクは既存の `../menu.html` を使用しています。

ローカル確認：プロジェクト直下で `python3 -m http.server 8765` を実行し、`http://localhost:8765/purichi/` を開きます。

## プリンを主役にしたデザイン更新

正式商品名「クラシック＃プリチ」と提供された商品説明を反映。カスタード黄色、カラメルの波形、3つの食感の説明を追加。メイン写真2点は以前制作したAI背景調整版を利用し、ギャラリーでは実写素材を掲載。
