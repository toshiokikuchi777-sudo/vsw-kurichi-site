■ ForgeCAD ギャラリー（クリチランド建築シミュレータ）の使い方

【起動する】
・建築シミュレータ …「ForgeCAD起動.command」をダブルクリック
・テキストスパイラル（ことばが立体になって螺旋をのぼるアプリ）
  …「スパイラル起動.command」をダブルクリック
→ サーバが立ち上がり、ブラウザで自動的に開きます
※初回だけmacOSが「開発元を確認できません」と出ることがあります
  → ファイルを右クリック →「開く」→「開く」で以後はダブルクリックOK
※AIブリッジ（ことばの意味から色・質感をAIが決める）も自動で起動します

【アプリとしてインストールする（Dockに常駐・単独ウィンドウ）】
起動した状態で:
・Chrome … アドレスバー右端の「インストール」アイコン（画面＋↓のマーク）をクリック
・Safari … メニューの「ファイル」→「Dockに追加」
→ 以後はDockのアイコンから普通のアプリのように起動できます
（アイコンとアプリ情報は kurichiland-forge/manifest.webmanifest で定義。
　manifest・icon-192.png・icon-512.png は index.html と同じフォルダに
　置く必要があるため、このフォルダには入れていません）

【主な機能】
・右側ツールバー: ビュー切替 / 透視・平行投影 / シェーディング / 計測 /
  断面 / 太陽光(日照) / レイヤー / 爆発図 / ウォーク / 文字 / スケッチ ほか
・「❓」ボタンでショートカット一覧が見られます

【困ったとき】
・画面が古いまま → Cmd+Shift+R で強制再読み込み
・「表示できませんでした」→ file://で直接開くと動きません。
  必ず「ForgeCAD起動.command」から開いてください
